# Cloud Security Audit - GCP Startup

-Description

A practical cloud security audit simulation focused on IAM exposure, networking flaws, metadata risk, exposed applications, and monitoring gaps within a startup environment on Google Cloud Platform.

-Environment Overview

- Multi-project GCP environment
- Shared Service accounts
- Public VM-hosted application
- Finance storage resources
- Logging and Monitoring Review

-Audit Scope

- IAM and Trust Boundaries
- Network Exposure
- Application Security
- Metadata Risk
- Storage Security
- Logging and Monitoring
- Backup and Recovery

-Key Findings

- Excessive IAM permissions
- Public application exposure
- Weak network segmentation
- Limited monitoring visibility
- Lack of a recovery protocol

-Severity Score

- Overall Score: 44/100 - High Risk

-Purpose

The repository demonstrates the process behind a practical cloud security audit designed for startup and SMB environments using the Google Cloud Platform.
