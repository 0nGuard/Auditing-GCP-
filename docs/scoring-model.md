# Scoring System

Scoring Model (100 points total) 

# IAM & Access — 25 points

• No Owner misuse → +10 

• Least privilege applied → +10 

• No long-lived keys → +5 

# Authentication — 15 points

• MFA enforced → +10 

• No shared/personal accounts → +5 

# Storage Security — 15 points

• No public buckets → +10 

• Proper access controls → +5 

# Networking — 15 points

• No open ports to world → +10 

• Restricted firewall rules → +5 

# Logging & Monitoring — 15 points

• Logs enabled → +10 

• Alerts configured → +5 

# Compute Security — 10 points

• No default service accounts → +5 

• Systems updated → +5 

# Backup & Recovery — 5 points

• Backups exist → +3 

• Restore tested → +2 

# Score meaning

• 100–80 → Strong 

• 79–60 → Moderate risk 

• 59–40 → High risk 

• <40 → Critical
